# Shomo brand pack: marks, type and glow

Working source files from the personal-brand exercise (Oct 18–19, 2026). `.vectorcraft` files open in VectorCraft and `.pcraft` files in PhotoCraft. Each `.jpg` or `.png` beside a source file is its export. This folder is not part of the published site.

## marks/
- `22_mark_routes`: the first wordmark, monogram and symbol routes.
- `24_marks_v2`: the second round of marks.
- `27_marks_v3`: the latest marks, with a smooth 16-bit light trail, "The Context Window", and the dot back on the parent Shomo mark.
- `25_symbol_infinity`: the infinity symbols, all rejected and kept for the record.
- `28_symbol_exponential`: eight J-curve symbols, no pick yet.
- `trail_master.pcraft` / `.png`: the light-trail master. `27_fix2_bandB_400.png` is a 400% crop of the smooth fade.

## type/
Type pairings, close-ups and hero tests (`12`–`16`). The type that was settled on is Newsreader (upright) as the main serif, with IBM Plex Mono for labels and supporting text (`16_newsreader_hero`).

## glow/
- `stage1/`: glow recipe studies on the ring reference, versions `glow_v1`–`v4` and boards `v1`–`v4`.
- `treatments/`: the halation (`10`) and atmosphere or fog (`11`) treatments.
- `10_halation.jpg`: halation B (subtle) was chosen.
- `11_atmosphere_v2.jpg`: fog B (light haze) was chosen.
- `grayscale_glow.md`: research notes on the glow recipe.

Some studies use third-party reference photos (for example the ring image), so check rights before publishing any of them.
